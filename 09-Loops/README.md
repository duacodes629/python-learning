# Loops

## What I Learned

Loops repeat code automatically.

## For Loop

```python
for i in range(5):
    print(i)
```

A for loop repeats a block of code a specific number of times.

## While Loop

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

A while loop repeats while a condition is True.
